## Convention candidates

Shapes stable enough to promote to AGENTS.md / canon.md cross-cutting principles when ≥3 instances exist and the shape is stable.

### 1. `[user-as-load-bearing-oversight]` — **PROMOTE NOW**

- **Name:** `[user-as-load-bearing-oversight]`
- **Instances counted:** **11+ total** (5+ pre-cycle per Retro #006 + 6+ this cycle).
- **Anti-pattern it closes:** `framework-discipline-mistaken-for-self-sufficiency`. The framework's mechanical checks (`[refuse-escalate]`, `[soft-spec-hardening]`, `[cite-or-mark-na]`, workflow gates, retro cadence, etc.) catch many patterns. They do NOT catch all patterns. The user catches the rest. Treating user corrections as friction (and trying to engineer them away by adding more mechanical checks) misses the structural insight — the user is part of the discipline loop, not external to it.
- **Proposed canon entry text:**
  > **`[user-as-load-bearing-oversight]`** — Compass-original pattern (v0.3.18). When framework discipline produces wrong-shaped output that mechanical checks miss, **the user catches it; the agent course-corrects.** This is not a failure mode of automation — it's the system working as designed. The framework's mechanical checks (refuse-escalate, soft-spec-hardening, workflow gates, retro cadence, freshness markers) cover most discipline lapses; the user closes the residual gap. **Discipline implications:** (1) Every QUEUED entry must declare explicit triggers — the user fires triggers via observation. (2) Every CHANGELOG entry should cite user observations as origin when applicable — keeps the load-bearing nature visible. (3) Course-corrects from the user are first-class signal, not friction; never engineer them away. (4) When a pattern recurs frequently (≥3 instances of the same correction), the framework should harden mechanically — but until then, the user's role IS the structural discipline. **First observability-class Compass-original — joins `[role-boundary]` as 2nd observability member** (currently solo).
- **Recommendation: PROMOTE TO CANON** in next improvement entry. Naming consideration: alternative is `[human-in-the-discipline-loop]` (more accurate framing) — pick at codification time.
