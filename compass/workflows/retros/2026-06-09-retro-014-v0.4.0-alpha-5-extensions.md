## Convention candidates

### 1. `[context-injection-discipline]`

- **Instances counted:** #64 (`--full-project` for orchestrator) + #68 (`--context-files` for dispatch.py) — 2 instances in this batch, same root cause named independently
- **Shape:** An agent called without domain context (PROJECT.md, bet brief, architecture decisions) is forced to guess intent — its output is structurally disconnected. Context injection is the caller's responsibility; the agent file defines WHAT to check, the caller provides the domain knowledge to check against. Two modes: (a) include for bet-aware reviews/analysis; (b) omit for pure structural checks (syntax, linting).
- **Proposed principle text:** *"Context injection is the caller's responsibility. An agent dispatched without domain context will produce structurally disconnected output. For any task requiring design-intent awareness, inject PROJECT.md + the bet's brief + architecture.md alongside the primary input."*
- **Recommendation:** **Wait for 3rd instance.** 2 instances (both in the same session) establishes the pattern but not yet from diverse friction sources. Next trigger: consumer using `dispatch.py` in CI without `--context-files` and getting a structurally disconnected review. That's the 3rd-instance signal.

### 2. `[ci-script-llm-discipline]`

- **Instances counted:** #66 (violation) + #67 (correction) — 1 incident, 1 hardening
- **Shape:** Any CI script, handoff script, or `compass/scripts/*.py` file that dispatches to an LLM must go through `dispatch.py → router.py → hosts/*.py`. Direct SDK imports (`import openai`, `import anthropic`) outside `hosts/*.py` are an architectural violation. The agent file's `preferred_hosts:` is the LLM routing source of truth.
- **Proposed principle text:** *"LLM SDK imports belong only in `compass/orchestrator/hosts/*.py`. Any script that needs to call an LLM uses `dispatch.py --agent-file <agent>.md`. Calling openai/anthropic SDK directly in a role script or CI file bypasses the routing matrix and is a violation."*
- **Recommendation:** **Wait for 2nd instance.** 1 incident is clear but the principle is already in memory (`feedback_llm_agnostic_scripts.md`) and enforced architecturally by `dispatch.py`. The codification trigger should be: a second script or contributor introduces direct SDK coupling despite the precedent. Memory serves as the holding state until then.
